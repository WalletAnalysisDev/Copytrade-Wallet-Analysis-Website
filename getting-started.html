Getting started

Set up in about a minute

Install the extension, add a free Helius key, and score your first wallet.

InstallGet a Helius keyScore a walletUse the filtersHelius creditsTips

1. Install the extension

Coming soon to the Chrome Web Store. The extension is in Google's review. This page will link to the listing as soon as it's approved.

Then pin it: click the puzzle icon in Chrome's toolbar and the pin next to Copytrade Wallet Score. Clicking its icon opens the side panel.

2. Get a free Helius API key

  1. Go to helius.dev and sign up. The free plan works.
  2. In the Helius dashboard, open API Keys and copy your key.
  3. In the extension, open the menu (three lines, top right) and paste it under Helius API keys.

You can add more than one key. When one runs out of monthly credits, the next is used automatically.

3. Score your first wallet

  1. Copy a wallet address, for example from a token's top traders on GMGN.
  2. Paste it into the Wallet tab and press Score.
  3. Read the score, its breakdown, and the filters vs all trades table.

To score many at once, paste a list with one wallet per line. To find wallets, use Top traders with a token you know did well.

4. Put the filters in your copy bot

Tap Min market cap, Max market cap, Min SOL buy and Max SOL buy to copy each value, and paste them into your copy bot's settings for that wallet. On GMGN wallet pages, In filter and Out of filter labels show which trades those filters would have taken.

Helius credits

Everything the extension reads from Helius uses credits from your plan. These are approximate costs:

ActionAbout
Score a new wallet100+ credits
Reopen a saved walletfree, or a few credits for new trades
Spike & round-trip check~20 credits per token
Top traders search~1,000 credits per 10,000 trades read
Holders check~10 credits per holder with wallet details

The extension shows the credits each scan used, and how many each key has used this month.

Tips

  • Turn off Auto-check spikes & round-trips for fast, cheap scans, then run the check on wallets that score well.
  • Use Only if score ≥ in Top traders so checks only run on promising wallets.
  • Lower Analyze tokens to 25 for faster scans of very active wallets.
  • A score with few trades behind it ("small sample") deserves less trust than the number suggests.
